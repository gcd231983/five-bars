Five Bars privacy information

How the site handles watchlists, financial calculator inputs and third-party links.

Data you enter

Five Bars runs its plan finder, comparison, personal watchlist and switching calculations in your browser. Your current wireless bill, phone payoff and switching expenses are not sent to a Five Bars database. Calculator inputs remain in the page for your current session; they are not saved as part of an account.

Plan preferences, saved comparisons, review acknowledgements and watchlists may be stored in your browser’s localStorage so you can return to them. Clearing browser storage or using private mode can delete these values. The watchlist offers an optional export/import backup. You can delete stored Five Bars data in your browser’s site-data controls.

Shared links and copied reports

Switch & Save share links exclude your personal bill, payoff and fee amounts by default. An explicitly requested report copy contains the numbers you entered. Anyone who receives your copied report can read those inputs. Treat report text as private if it includes personal financial details. A user may also choose to construct a share link with financial parameters; links containing them can be visible in browser history and to anyone receiving the link.

Hosting and external services

Five Bars is served from GitHub Pages. Hosting infrastructure may process technical request information such as IP addresses and user agents under the host’s own policies. The website currently loads a font stylesheet from Google Fonts, whose requests are made to Google. Clicking carrier, GitHub or government links sends you to a separate site governed by its own practices.

This repository does not contain an advertising analytics SDK, visitor login system, email marketing list, or personalized server-side watchlist database. That can change in future releases; this page should be revised before enabling such integrations.

Contact and changes

For non-sensitive catalog corrections, prepare a public correction report. There is currently no private support inbox. Do not post personal privacy concerns or identifiable subscriber records in public GitHub issues. Do not post your phone number, account number, private PIN, payment information or other sensitive details in public issues. We will update this notice if features or providers change.

Reader correction reports

The report assistant loads public catalog data and prepares text locally. It does not send your draft to Five Bars, save the draft in localStorage, or automatically post a GitHub issue. The public GitHub issue form requires a GitHub account. If you choose to paste and submit a report there, GitHub handles that public content under its own privacy rules. Do not include subscriber or account details. Basic local warnings cannot detect every type of personal information.
